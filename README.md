# Shwetaleena Kundu — Frontend Developer Portfolio

A responsive personal portfolio created for my Week 1 internship assignment. It introduces me, shows my frontend projects, and provides a way to contact me.

## Technologies used

HTML, CSS, and JavaScript. The contact form uses FormSubmit.

## Features

- Home, About, Projects, and Contact pages
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- Six projects with screenshots, live links, and GitHub links
- Load more and Show less project buttons
- Contact form, email link, and GitHub link

## Folder structure

- `index.html` — Home page
- `about.html` — About page
- `projects.html` — Projects page
- `contact.html` — Contact page
- `css/` — Main and responsive styles
- `js/` — Navigation and project button behavior
- `assets/images/` — Project images
- `screenshots/` — Assignment screenshots

## Run locally

Open the `Portfolio` folder in VS Code. Open `index.html` with Live Server. No installation is required.
